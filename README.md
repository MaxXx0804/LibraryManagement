Setting up the project

Download Visual Studio
Open Visual Studio -> Clone project copy this link -> https://github.com/MaxXx0804/LibraryManagement
Select Project > Manage NuGet Packages.
In the NuGet Package Manager page, choose nuget.org as the Package source.
Click the Updates -> Select all packages and Update.

Setting up Database Server

Install SSMS
Install SQL Express -> Choose the Express one

Download the file named "LibraryManagementSystem.bak"

Open SSMS -> Click the arrow on the right and click Browse for more
Click on database engine and click the first one
Click Connect
On the left side right click the databases
Click Restore Database -> Click the Device radio button
Click on the "..." click add then find the file you downloaded earlier named "LibraryManagementSystem.bak"

Run the program
